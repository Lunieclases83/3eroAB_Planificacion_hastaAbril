# Plataforma de 3.º de secundaria — CAJPD

Incluye el programa hasta marzo, cronograma, clases por bloques, rúbrica de hoy y logo institucional.

## Subir a GitHub
1. Descomprime el ZIP.
2. Abre la carpeta Plataforma_Tercero_HTML.
3. Sube TODO SU CONTENIDO a la raíz del repositorio, conservando la carpeta assets.
4. index.html debe quedar directamente en la raíz, junto a data.json y assets.
5. Confirma los cambios. Para publicarlo con GitHub Pages, selecciona la rama que contiene estos archivos y la carpeta raíz (/).

No subas únicamente el ZIP: GitHub Pages necesita los archivos descomprimidos.
El logo ya está conectado mediante assets/logo-cajpd.png.
No necesitas instalar programas ni compilar el proyecto.

## Uso
Consulta el sitio desde una dirección web. Abrir index.html por doble clic puede impedir que el navegador cargue data.json; para revisarlo localmente utiliza un servidor web local.
Las puntuaciones del instrumento se calculan en pantalla y pueden imprimirse, pero no se guardan ni sincronizan. El cronograma es una planificación; los avances se actualizan con confirmación docente.

## Seguimiento por sección y bloque
En «Clase por bloques», elige fecha y sección, selecciona el estado de la clase y de cada bloque, añade observaciones y pulsa «Guardar registro de esta sección».
Los cambios se guardan solo en ese navegador, equipo y dirección web. No hay sincronización automática ni cuentas docentes.
Para compartir con el coordinador: descarga seguimiento.json desde la plataforma y reemplaza ese archivo en la raíz del repositorio GitHub. La versión publicada se verá desde otros dispositivos.
«Importar respaldo» recupera un archivo de seguimiento y reemplaza los registros locales: exporta primero tus cambios actuales.
